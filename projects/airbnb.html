New York Airbnb price modeling

Cleaning rental listing data and comparing linear and ridge regression through five-fold cross-validation.

The question

How can rental listing characteristics be prepared for a model of New York Airbnb prices, and how do linear and ridge regression compare?

My approach

  • Removed four duplicate records and a constant-value column from the supplied dataset.
  • Handled missing numeric and categorical values using mean and most-frequent imputation.
  • Encoded room type and price level, standardized the data, and compared two regression methods with five-fold cross-validation.

What the notebook shows

The dataset contains 48,895 listings after duplicate removal. Linear and ridge regression produce nearly identical errors in this assignment. Across the five folds, saved RMSE values range from approximately $184.68 to $247.28. These are individual fold results, not a single overall performance estimate.
