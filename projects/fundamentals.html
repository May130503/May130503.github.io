R / R Programming

Patterns, plots & programming in R

Using conditional styling, for loops, and while loops to explore data and express repeatable logic.

The question

How can basic R programming make a plot more informative and automate repeated tasks?

My approach

  • Loaded age and IGF-1 observations from the ISwR juul dataset.
  • Used conditional colors and point shapes to distinguish observations above age 75.
  • Generated an odd-number sequence with both for and while loops.
  • Added a conditional branch to print “three” when the sequence reaches 3.

What this demonstrates

This foundational exercise connects vectorized conditions, plot styling, iteration, and branching in a single R workflow.
