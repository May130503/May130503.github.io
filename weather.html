Python / Machine Learning for Business

From weather data to model inputs

Transforming weather observations into a prepared dataset, with missing-value handling and exploratory visualizations.

The question

How can weather observations be cleaned, transformed, and organized for a machine learning workflow?

My approach

  • Converted humidity into a binary indicator using a threshold of 0.5.
  • Imputed missing numeric and categorical values and encoded the Rain variable.
  • Separated features and target, then created an 85% training and 15% test split with a fixed random seed.
  • Explored temperature and wind speed with a scatterplot and a boxplot.
